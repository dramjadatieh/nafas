# نفس

تطبيق شخصي لتتبع العادات وتخفيف الدخان (PWA). بيشتغل على الآيفون والسامسونج، وبيتزامن بينهم عن طريق Firebase.

## الملفات
- `index.html`: التطبيق كله
- `config.js`: إعدادات Firebase
- `sw.js`: بيخلي التطبيق يفتح بدون نت
- `manifest.webmanifest` و `icon-*.png`: الاسم والأيقونة لما تضيفه للشاشة الرئيسية
- `firestore.rules`: قواعد الحماية. كل حساب بيشوف بياناته بس

ما في أي بيانات شخصية بهالملفات. كل الأرقام بتندخل من جوا التطبيق وبتنحفظ بحسابك.
